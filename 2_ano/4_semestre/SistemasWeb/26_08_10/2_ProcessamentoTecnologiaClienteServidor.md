# Processamento Tecnologia Cliente-Servidor

* Para que a tecnologia cliente servidor seja observada na prática, é preciso considerar a execução de:
  * Dispositivos de hardware
    * Servidores, hubs, switches, etc.
  * Elementos de software:
    * Sistema operacional (SO)
    * Aplicações relacionadas (processos)

* Entre os dispositivos e elementos, estão cliente e servidor
* Ambos são processos
* O cliente pode ser escrito como um processo ativo (inicia e termina a interação), responsável pela entrada e saída de dados
* O servidor pode ser entendido como um processo reativo (responde com o que é solicitado), que atende as demandas do cliente
